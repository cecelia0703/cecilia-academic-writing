# Academic argument
- Start with the actual question/rubric and formulate a responsive thesis.
- Outline why each paragraph matters and which verifiable evidence supports it.
- Explain evidence rather than merely listing readings or describing examples.
- Add limitations, alternative interpretations, or counterarguments only when substantively relevant.
- Ensure successive sentences contribute new facts, reasoning, distinctions, or implications.
- For practice-based writing, distinguish project design choices, observed outcomes, and claims supported by literature.

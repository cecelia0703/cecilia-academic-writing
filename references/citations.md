# Citation and evidence protocol
- Prefer supplied course readings and authoritative primary scholarship; independently verify any new sources where tools allow.
- Never invent a source, quote, DOI, page range, date, or bibliographic element.
- Track exact support for each material academic claim. Quote only from actually inspected source text.
- Distinguish author's argument from the user's inference.
- Match the course-prescribed style (Chicago footnotes and bibliography, Chicago author-date, APA 7, Harvard, etc.).
- For Chicago Notes & Bibliography, inspect footnote sequence, citation completeness, book/article title treatment, relevant page locators, and bibliography correspondence.
- Mark elements that cannot be verified: [source verification needed], [page number needed].

# Minimal-edit revision protocol
1. Read the whole passage for argument and author intention.
2. Prioritize factual/citation errors, serious grammar, unclear meaning, reasoning gaps, then repetitive or stiff wording.
3. Keep correct sentences unchanged even if another formulation sounds more sophisticated.
4. Preserve examples, cited claims, structure and intended stance. Explain any truly necessary large changes.
5. When reporting edits use: Must fix / Recommended / Optional; optionally show 'Original → Revised → Why'.
6. Final pass: rubric, word count, references, Chinese-to-English calques, repetition, and mechanical rhetorical patterns.
7. Never describe a heuristic style check as proof a passage was generated by AI.

# Cecilia Academic Writing Skill v1.1

Personal English academic-writing skill tailored for clear, natural language, academic integrity, assignment-specific citation standards, and minimal necessary revision.

## Contents
- SKILL.md: primary skill instructions
- references/: style, argument, citations, revisions
- scripts/check_academic_writing.py: optional heuristic phrase check
- examples/: illustrative editing examples

## Use
Place the cecilia-academic-writing folder in a tool's supported skills directory, according to that tool's documentation. Run python scripts/check_academic_writing.py path/to/essay.txt for optional pattern reminders.

## Origin
Custom interpretation inspired by the user-provided KKKKhazix/human-writing project: https://github.com/KKKKhazix/human-writing . It is a new skill customized for English academic writing, not a verbatim copy.
